## 二、关键实现

### 2.1 基建（对照清单 §五 卡点 #6）

- `request.ts`：axios 实例 baseURL=`/api`；请求拦截挂 `Authorization: Bearer <token>`；响应拦截 `code!==200` → ElMessage.error + reject；**HTTP 401 / code 401 统一清 token 跳 `/login?redirect=`**（JWT 过滤器抛的 401 不走后端 advice，前端认状态码；清单 #6 已预告）。
- `store/user.ts`：token + userInfo 存 localStorage（`utils/storage.ts`，前缀 `trip_`），login() 写登录返回的 LoginVO。登出自动清。
- `router/`：`/` 下挂 UserLayout 子路由 8 条（Home/RouteList/RouteDetail/DestinationList/PlanList/PlanCreate/PlanEdit/Favorites/Bookings）+ 独立 `/login` `/register`；`guard.ts` 未登录访问非 public 页 → 跳登录带 redirect；`document.title` 统一。
- `tsconfig.app.json` 加 `paths: { "@/*": ["./src/*"] }`（**不写 baseUrl**——TS 6 已废弃 baseUrl，直接相对 paths）。

### 2.2 页面要点

- **RouteDetail**：大图+标签+统计、操作条（点赞/收藏/预约/一键生成规划）、按天 `el-tabs`+ `el-timeline` 展开行程项、评论区（星级+文字、按情感筛选、AI 情感标签展示）、预约弹窗（日期≥今天）。
- **PlanEditor**：基本信息（标题/出发日期/人数/多选目的地/预算）→ 按天 Tab（标题可内联改名、+添加一天/删除最后一天）→ 天内 `vuedraggable`（group=`plan-items` 支持**跨天拖拽**）→「从景点库添加」抽屉（`GET /destination/{id}/attractions`，完成线 7）→ 右栏预算进度条（超支变红）→ 保存草稿(status=0)/保存正式(status=1，需每天≥1项)。
  - **BR-PLN-03 前端侧**：保存不传自定义 dayIndex/sortNo（仅按数组顺序传 `dayList.items` 的 `sortNo=i+1`），由服务端重排。
  - 编辑模式 `GET /plan/{id}` 深加载 dayList 双向绑定；`?fromRoute={id}` 走 `POST /plan/from-route/{routeId}`（路线详情页"一键生成规划"入口）。
  - AI 优化按钮按 PLN-09 规则置灰（第 3 批实装）。
- **PlanList**：分页列表 + 编辑/复制(`/plan/{id}/copy`)/导出(`/plan/{id}/export` 对话框展示文本行程单)/删除(`DELETE /plan/{id}`)。
- **Favorites/Bookings**：`GET /interaction/favorite/page`（返回 RoutePageVO 复用 RouteCard）、`GET /interaction/booking/page` + 取消 `PUT /interaction/booking/{id}/cancel` + 状态标签。
