### 1.3 性能设计
- 聚合结果 Redis 缓存，TTL 5 分钟；大屏轮询间隔 ≥ 30 秒
- 数据量增长后改为定时任务预聚合到 `stat_daily` 宽表
- 自适应：设计稿 1920×1080，运行时按容器宽高 `scale` 缩放

## 二、前端实现方案（`DataScreen.vue`）


**自适应方案**

```ts
const scale = ref(1);
function resize() {
  scale.value = Math.min(window.innerWidth / 1920, window.innerHeight / 1080);
}
// 容器：transform: scale(scale) ; transform-origin: left top;
// 外层黑底居中放置
```

**布局（1920×1080 基准）**

| 区域 | 尺寸 | 内容 |
|---|---|---|
| 顶部标题栏 | 1920×90 | 标题 + 日期时间 + 全屏按钮 + 返回后台 |
| 指标卡区 | 1860×130 | 4 张指标卡（今日访问 / 路线总数 / 本月预约 / AI 对话） |

**ECharts 封装要点**

```ts
// utils/echarts.ts
import * as echarts from 'echarts/core';
import { LineChart, BarChart, PieChart, MapChart, ScatterChart } from 'echarts/charts';
import { GridComponent, TooltipComponent, LegendComponent, GeoComponent } from 'echarts/components';
import { CanvasRenderer } from 'echarts/renderers';
echarts.use([LineChart, BarChart, PieChart, MapChart, ScatterChart,
             GridComponent, TooltipComponent, LegendComponent, GeoComponent, CanvasRenderer]);

export const chartTheme = {
  color: ['#3BA0FF', '#36C99E', '#FFB74D', '#B18CFF', '#FF7A7A'],
  textColor: '#B8CBE8',
  gridColor: 'rgba(120,170,255,0.12)'
};

export function useChart(elRef: Ref<HTMLElement | undefined>, optionGetter: () => any) {
  let chart: echarts.ECharts | null = null;
  onMounted(() => {
    chart = echarts.init(elRef.value!, undefined, { renderer: 'canvas' });
    chart.setOption(optionGetter());
    window.addEventListener('resize', resize);
  });
  function resize() { chart?.resize(); }
  watch(optionGetter, (o) => chart?.setOption(o, true), { deep: true });
  onBeforeUnmount(() => { window.removeEventListener('resize', resize); chart?.dispose(); });
  return { resize };
}
```

- 地图使用高德地图 GeoJSON（`china.json`）本地引入，避免 CSP 与网络问题
- 词云使用 `echarts-wordcloud` 扩展
