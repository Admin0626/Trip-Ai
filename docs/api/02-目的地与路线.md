# 接口文档 · 目的地与路线

> 2026-09-28实际交付：公开读取保持`/destination/**`和`/route/**`；管理员目录写操作实际使用下方`/admin/catalog/**`，本分册旧设计表中的`POST /route`等写路径不作为当前实现路径。页面位于`/admin/destinations`、`/admin/routes`，实测见[基础后台记录](../dev/基础后台接口与页面实测.md)。

| 方法 | 实际管理路径 | 行为 |
|---|---|---|
| GET / POST | `/admin/catalog/destinations` | 管理分页/新增 |
| GET / PUT / DELETE | `/admin/catalog/destinations/{id}` | 详情/修改/逻辑删除；有关联路线删除409 |
| PUT | `/admin/catalog/destinations/{id}/status` | JSON整数status=0或1 |
| GET / POST | `/admin/catalog/destinations/{id}/attractions` | 景点列表/新增 |
| PUT / DELETE | `/admin/catalog/attractions/{id}` | 景点修改/逻辑删除 |
| GET / POST | `/admin/catalog/routes` | 管理分页/新增含每日行程 |
| GET / PUT / DELETE | `/admin/catalog/routes/{id}` | 详情/整套修改/逻辑删除；有预约记录删除409 |
| PUT | `/admin/catalog/routes/{id}/status` | status=0或1；上架要求父目的地已上架 |
| PUT | `/admin/catalog/routes/{id}/top` | isTop=0或1 |
| PUT | `/admin/catalog/routes/{id}/weight` | recommendWeight为0—1的JSON数字，最多4位小数 |

管理分页current=1—1000000、size=1—100，keyword可选，status可选0/1；路线另有destinationId筛选。路线dayList有1—30天，每天1—15项，days必须等于数组长度，序号由数组顺序生成。字符串/整数/金额拒绝隐式类型转换。普通用户403、匿名401；公开入口仅展示路线及父目的地均已上架的内容；历史预约/评论由管理员继续管理。

> 本文是 [`02-接口文档.md`](../02-接口文档.md) 的分册之一。
> 通用约定（请求头、统一响应体、分页、状态码、鉴权）与文件上传接口见主文档。
> 覆盖功能编号：**DST-01 ~ DST-10、RTE-01 ~ RTE-13**
> 覆盖接口前缀：`/destination/**`、`/route/**`

## 目的地模块 `/destination`

| 方法 | 路径 | 说明 | 权限 |
|---|---|---|---|
| GET | `/destination/page` | 分页查询目的地 | 公开 |
| GET | `/destination/list` | 全部上架目的地（下拉用） | 公开 |
| GET | `/destination/{id}` | 目的地详情 | 公开 |
| GET | `/destination/hot` | 热门目的地 TOP N | 公开 |
| GET | `/destination/provinces` | 省份列表（筛选用） | 公开 |
| POST | `/destination` | 新增目的地 | ADMIN |
| PUT | `/destination/{id}` | 修改目的地 | ADMIN |
| DELETE | `/destination/{id}` | 删除目的地（逻辑删除） | ADMIN |
| PUT | `/destination/{id}/status` | 上下架 | ADMIN |
| GET | `/destination/{id}/attractions` | 目的地下的景点列表 | 公开 |
| POST | `/destination/{id}/attraction` | 新增景点 | ADMIN |
| PUT | `/attraction/{id}` | 修改景点 | ADMIN |
| DELETE | `/attraction/{id}` | 删除景点 | ADMIN |

查询参数：`current` `size` `keyword` `province` `tag` `status`

## 路线模块 `/route`

| 方法 | 路径 | 说明 | 权限 |
|---|---|---|---|
| GET | `/route/page` | 分页查询路线（含多条件筛选） | 公开 |
| GET | `/route/{id}` | 路线详情（含行程明细） | 公开 |
| GET | `/route/{id}/days` | 路线行程明细 | 公开 |
| GET | `/route/hot` | 热门路线 TOP N | 公开 |
| GET | `/route/recommend/home` | 首页推荐位路线 | 公开 |
| GET | `/route/search/suggest` | 搜索联想词 | 公开 |
| POST | `/route` | 新增路线（含行程） | ADMIN |
| PUT | `/route/{id}` | 修改路线 | ADMIN |
| DELETE | `/route/{id}` | 删除路线 | ADMIN |
| PUT | `/route/{id}/status` | 上架 / 下架 | ADMIN |
| PUT | `/route/{id}/top` | 设置 / 取消置顶 | ADMIN |
| PUT | `/route/{id}/weight` | 设置人工推荐权重 | ADMIN |
