## 数据统计与大屏 `/analysis`

### 2026-10-04实际交付：后台数据与可视化

实际接口为`GET /admin/analysis/dashboard?days=30&destinationId=1`，仅ADMIN。days可选7/30/90，默认30；destinationId可省略，存在时须为正整数且不超过JS安全整数上限、对应未删除目的地。匿名HTTP401，普通用户HTTP403；参数业务错误HTTP200/code400，不存在/已删除目的地code404。

页面`/admin/analytics`提供预约/新增用户/模型记录折线、目的地预约Top10柱状图、路线人均参考价/预约单数散点图、预约状态和模型结果柱状图、路线与每日明细。读取现有业务表，不读取种子stat_daily或ai_insight；无新SQL迁移和定时任务，无模型调用。

响应统一包装`{code,message,data}`，data包含：

| 字段 | 口径 |
|---|---|
| generatedAt、timezone、days、startDate、endDate、destinationId | 北京时间Asia/Shanghai，今天和前days-1日；日期范围为[startDate 00:00, endDate次日00:00)，包含今天 |
| summary.users/newUsers | 全站未注销账号当前总数/窗口内创建数，含管理员及停用账号；目的地筛选不影响 |
| summary.routes | 当前筛选下未删除路线与未删除目的地的关联路线数，含上下架 |
| summary.bookings/cancelled | 上述有效目录范围内按create_time计入窗口的预约单数/其中当前status=2的单数；取消数不是当天实际取消动作，单数不是人数 |
| summary.aiCalls/aiSucceeded/aiAverageMs | 全站窗口内llm_call_log行数/成功行数/全部日志平均耗时ms；无记录时平均为null。可能含重试，不等于用户操作次数、token或费用 |
| trend | 按日期升序，恰好days项；date/bookings/cancelled/newUsers/aiCalls，无记录日补0 |
| destinationHeat | id/name/bookings，实际预约聚合Top10，按预约单数降序、目的地ID升序；无预约返回空数组 |
| routeScatter | id/title/destinationId/destination/price/days/status/bookings；price为当前路线人均参考价，不是实收；含零预约路线 |
| matchingRoutes/scatterLimit | 当前匹配路线总数/100；仅返回预约量最高100条（同量ID升序），页面明确截断，不把其称为全量分布 |
| bookingStatuses/aiStatuses | 固定4项当前预约状态（0待确认/1已确认/2已取消/3已完成）和2项模型结果（1成功/0失败），无记录数为0 |
| destinations/destinationTotal/destinationLimit | 当前未删除目的地选项id/name、总数、1000；按name/id取前1000，全部范围统计仍包含有效全量；页面显示选项上限 |

后端使用只读REPEATABLE_READ事务，多个图表取同一数据库快照；预约先分组再关联路线，避免JOIN放大或冗余booking_count失真。历史预约关联已删除路线/目的地不纳入此目录分析；历史账号注销不抹除预约/模型历史。接口不返回联系人、电话、密钥、用户名、提示词或日志错误正文。

[实际接口/SQL及页面验收、缺陷和答辩说明](../dev/后台数据可视化实现与验收.md)。下面原`/analysis/**`表为未来设计合同，尚未提供这些独立接口，不能把其样例数字当实际指标。全屏/sentiment/AI洞察/Excel导出/日预聚合等仍待开发。

2026-09-27实际交付：上述提交、我的分页、管理员分页和回复接口已真实验收；单独详情、仅改状态和删除仍未实现。图片最多3张，只接受本站上传返回的32位小写十六进制`.png/.jpg`路径；标题100字、正文2000字、联系方式可选100字，contact必须为字符串或null。用户ID从登录身份取得，管理员分页可带status=0/1/2/3；current≥1且≤1000000，size=1—100。

回复请求（**新增必填expectedStatus，旧调用方需同步更新**）：

```json
{"expectedStatus":0,"status":1,"replyContent":"正在核查问题"}
```

expectedStatus是页面读取时的整数状态，必须与当前数据库一致，否则业务409。合法转换仅0→1/3、1→2/3，终态2/3禁止修改回复。replyContent非空且≤2000字；并发更新使用状态CAS。列表返回images数组、contact、replyContent、replyTime等，用户可回看处理结果。状态/参数错误HTTP200/code400，冲突HTTP200/code409，未找到HTTP200/code404；认证/权限分别HTTP401/403。管理员页面有20条分页、状态筛选和终态只读。证据及限制见[本批实测](../dev/管理员反馈接口与页面实测.md)、[开发复盘](../dev/管理员反馈开发复盘.md)。

### 用户管理 `/admin/user`

## 本批已实现的数据工具（2026-10-03）

### GET /admin/user/export

ADMIN；查询keyword（用户名/昵称，最多100字）、status（可选0/1），与用户列表相同。导出全部匹配的未删除用户，ID降序，最多5000；超过限制返回code400要求缩小范围，不静默截断。成功直接返回text/csv;charset=UTF-8的附件、UTF-8 BOM、no-store；8列：用户ID、用户名、昵称、城市、角色、状态、注册时间、最后登录时间。无密码/Token/手机号/邮箱；危险表格公式文本加前置单引号。

### POST /admin/catalog/import/preview 与 /commit

ADMIN；multipart/form-data，file字段为JSON，1至50条、最多1MiB。根对象为 `{"version":1,"type":"DESTINATION","records":[...]}`；type也可ATTRACTION/ROUTE。根/记录未知字段、重复JSON键及宽松数字类型不接受。record沿用CatalogSaveDTO字段；景点额外要求destinationId，路线支持dayList/items嵌套。必须status=0，目的地先建后引景点/路线；模板可在/admin/import下载。

preview返回 `data={type,total,valid,rows:[{index,name,valid,errors}]}`，不写库。

commit额外字段requestId（小写UUID）、confirmation=确认导入；不依赖前次预览成功，重新校验并原子新增整批，返回 `data={type,total,ids,replayed}`。任一行错误code400；同一管理员同UUID同文件回放ids且replayed=true，同UUID不同文件code409；同名内容（含删除记录）拒绝，不覆盖。业务错误通常HTTP200；认证/ADMIN权限由过滤器返回401/403。详细名称比较、关系约束、失败响应及迁移见实测/开发文档。
