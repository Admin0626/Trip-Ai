| 方法 | 路径 | 说明 | 权限 |
|---|---|---|---|
| POST | `/feedback` | 提交反馈 | USER |
| GET | `/feedback/my/page` | 我的反馈 | USER |
| GET | `/admin/feedback/page` | 全部反馈 | ADMIN |
| GET | `/admin/feedback/{id}` | 设计条目，待实现；当前分页已返回详情字段 | ADMIN |
| PUT | `/admin/feedback/{id}/reply` | 回复并更新状态 | ADMIN |
| PUT | `/admin/feedback/{id}/status` | 设计条目，待实现；当前状态随回复修改 | ADMIN |
| DELETE | `/admin/feedback/{id}` | 设计条目，待实现 | ADMIN |

```json
{
  "type": "FUNCTION",
  "title": "AI 推荐偶尔超时",
  "content": "输入较长描述时页面卡住，希望增加超时提示。",
  "images": ["/api/files/0123456789abcdef0123456789abcdef.png"],
  "contact": "13800000000"
}
```
`type`：FUNCTION 功能建议 / BUG 缺陷 / CONTENT 内容纠错 / OTHER
`status`：0 待处理 / 1 处理中 / 2 已解决 / 3 已关闭

2026-09-27实际交付：上述提交、我的分页、管理员分页和回复接口已真实验收；单独详情、仅改状态和删除仍未实现。图片最多3张，只接受本站上传返回的32位小写十六进制`.png/.jpg`路径；标题100字、正文2000字、联系方式可选100字，contact必须为字符串或null。用户ID从登录身份取得，管理员分页可带status=0/1/2/3；current≥1且≤1000000，size=1—100。

回复请求（**新增必填expectedStatus，旧调用方需同步更新**）：

```json
{"expectedStatus":0,"status":1,"replyContent":"正在核查问题"}
```

expectedStatus是页面读取时的整数状态，必须与当前数据库一致，否则业务409。合法转换仅0→1/3、1→2/3，终态2/3禁止修改回复。replyContent非空且≤2000字；并发更新使用状态CAS。列表返回images数组、contact、replyContent、replyTime等，用户可回看处理结果。状态/参数错误HTTP200/code400，冲突HTTP200/code409，未找到HTTP200/code404；认证/权限分别HTTP401/403。管理员页面有20条分页、状态筛选和终态只读。证据及限制见[本批实测](../dev/管理员反馈接口与页面实测.md)、[开发复盘](../dev/管理员反馈开发复盘.md)。

### 用户管理 `/admin/user`

2026-09-28实际交付：`GET /admin/user/page?current=1&size=20&keyword=...&status=0|1`及`PUT /admin/user/{id}/status`。其他下表接口和角色/注册时间筛选仍为设计项。分页current为1—1000000、size为1—100，返回id、username、nickname、city、role、status、createTime、lastLoginTime，不返回密码、手机号、邮箱或token。启停请求`{"status":0}`或`{"status":1}`，必须是JSON整数；只允许普通用户，管理员409，缺失用户404。改变状态会撤销Redis会话，恢复后须重新登录；登录与状态修改共享用户行锁，撤销失败返回503。管理页`/admin/users`已接入，见[本批实测](../dev/基础后台接口与页面实测.md)。

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/admin/user/page` | 用户分页（关键词 / 状态 / 角色 / 注册时间） |
| GET | `/admin/user/{id}` | 用户详情（含行为统计） |
| PUT | `/admin/user/{id}/status` | 启用 / 禁用 |
| PUT | `/admin/user/{id}/reset-password` | 重置密码 |
| PUT | `/admin/user/{id}/role` | 调整角色 |
| DELETE | `/admin/user/{id}` | 删除用户 |
| GET | `/admin/user/export` | 导出用户 Excel |
