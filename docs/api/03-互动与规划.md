## 互动模块 `/interaction`

| 方法 | 路径 | 说明 | 权限 |
|---|---|---|---|
| POST | `/interaction/like` | 点赞 / 取消点赞 | USER |
| GET | `/interaction/like/{routeId}/status` | 查询点赞状态 | USER |
| POST | `/interaction/favorite` | 收藏 / 取消收藏 | USER |
| GET | `/interaction/favorite/page` | 我的收藏（分页） | USER |
| POST | `/interaction/booking` | 提交预约 | USER |
| GET | `/interaction/booking/page` | 我的预约列表 | USER |
| PUT | `/interaction/booking/{id}/cancel` | 用户取消预约 | USER |
| GET | `/admin/interaction/booking/page` | 全部预约（管理端） | ADMIN |
| PUT | `/admin/interaction/booking/{id}/status` | 审核预约状态 | ADMIN |
| POST | `/interaction/comment` | 发表评论 | USER |
| GET | `/interaction/comment/page` | 路线评论分页 | 公开 |
| DELETE | `/interaction/comment/{id}` | 删除自己的评论 | USER |
| POST | `/interaction/comment/{id}/like` | 评论点赞 | USER |
| GET | `/admin/interaction/comment/page` | 评论管理分页 | ADMIN |
| PUT | `/admin/interaction/comment/{id}/status` | 显示 / 隐藏评论 | ADMIN |
| GET | `/admin/interaction/stat/{routeId}` | 单条路线互动统计 | ADMIN |

**POST /interaction/like**
```json
{ "routeId": 201 }
```
响应：
```json
{ "code": 200, "data": { "liked": true, "likeCount": 329 } }
```

**POST /interaction/favorite**
```json
{ "routeId": 201 }
```
响应：`{ "favorited": true, "favoriteCount": 146 }`

**POST /interaction/booking**
```json
{
  "routeId": 201,
  "travelDate": "2026-10-01",
  "peopleNum": 2,
  "contactName": "张三",
  "contactPhone": "13800000000",
  "remark": "希望安排靠窗房间"
}
```
响应：`{ "bookingId": 9001, "bookingNo": "BK20260916001", "status": 0 }`
状态枚举：0 待确认 / 1 已确认 / 2 已取消 / 3 已完成

**POST /interaction/comment**
```json
{ "routeId": 201, "parentId": null, "score": 5, "content": "行程安排很合理，导游专业！", "images": ["https://oss.../1.jpg"] }
```
响应（异步触发 AI 情感分析）：
```json
{
  "id": 5001,
  "sentiment": "positive",
  "sentimentScore": 0.973
}
```

## 自主规划模块 `/plan`

| 方法 | 路径 | 说明 | 权限 |
|---|---|---|---|
| POST | `/plan` | 创建规划（草稿或正式保存） | USER |
| PUT | `/plan/{id}` | 更新规划 | USER |
| GET | `/plan/page` | 我的规划列表 | USER |
| GET | `/plan/{id}` | 规划详情 | USER |
| DELETE | `/plan/{id}` | 删除规划 | USER |
| POST | `/plan/{id}/copy` | 复制规划为新规划 | USER |
| POST | `/plan/{id}/export` | 导出文字版行程单 | USER |
| POST | `/plan/from-route/{routeId}` | 以系统路线为模板生成规划 | USER |
| POST | `/plan/{id}/ai-optimize` | ★ AI 优化该规划（SSE 流式） | USER |

**POST /plan**
```json
{
  "title": "我的云南 5 日自由行",
  "destinationIds": [1, 2],
  "startDate": "2026-10-01",
  "days": 5,
  "budget": 3000.00,
  "peopleNum": 2,
  "status": 1,
  "dayList": [
    {
      "dayIndex": 1, "title": "大理古城",
      "items": [
        { "sortNo": 1, "timePoint": "10:00", "attractionId": 101,
          "title": "大理古城", "activity": "漫步古城", "transport": "步行",
          "hotel": "古城客栈", "meal": "白族三道茶", "durationMin": 150, "cost": 100.00 }
      ]
    }
  ]
}
```

**POST /plan/{id}/ai-optimize**（SSE）
```
event: intent
data: {"goal":"优化节奏与景点顺序"}

event: token
data: {"text":"第一天的行程"}

event: token
data: {"text":"安排略显紧张，"}

event: done
data: {"suggestions":[{"dayIndex":1,"issue":"景点间距离远","suggestion":"将洱海骑行调整到第二天上午"}],"optimizedPlan":{...}}
```
