## ★ AI 智能推荐模块 `/ai/recommend`

| 方法 | 路径 | 说明 | 权限 |
|---|---|---|---|
| POST | `/ai/recommend/intent` | 自然语言 → 结构化意图（NL2JSON） | USER |
| POST | `/ai/recommend/match` | 基于意图召回 + 重排，返回 Top N | USER |
| POST | `/ai/recommend/itinerary` | 生成细化行程（SSE 流式） | USER |
| POST | `/ai/recommend/one-shot` | 一站式：意图 + 召回 + 生成（SSE） | USER |

## SSE 接入约定

| 项 | 约定 |
|---|---|
| 请求方式 | `POST` + `fetch` 流式读取（原生 EventSource 不支持自定义头，故用 fetch + ReadableStream） |
| 响应头 | `Content-Type: text/event-stream`、`Cache-Control: no-cache`、`X-Accel-Buffering: no` |
| 事件类型 | `start` / `intent` / `recall` / `token` / `references` / `error` / `done` |
| 心跳 | 每 15s 发送 `: heartbeat` 注释行 |
| 超时 | 服务端 120s，前端 130s 未收到 `done` 则主动断开并提示重试 |
| 错误 | 发送 `event: error` + `data: {"code":3001,"message":"AI 服务暂时不可用，已为你切换到基础推荐"}` |
| 取消 | 前端 AbortController 中断，服务端检测连接断开后停止生成 |

前端调用示例：
```ts
export function ssePost(url: string, body: any, handlers: Record<string, (d: any) => void>) {
  const ctrl = new AbortController();
  fetch(url, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json', Authorization: `Bearer ${getToken()}` },
    body: JSON.stringify(body),
    signal: ctrl.signal
  }).then(async res => {
    const reader = res.body!.getReader();
    const decoder = new TextDecoder();
    let buf = '';
    while (true) {
      const { done, value } = await reader.read();
      if (done) break;
      buf += decoder.decode(value, { stream: true });
      const blocks = buf.split('\n\n');
      buf = blocks.pop() || '';
      for (const block of blocks) {
        const event = /event: (\w+)/.exec(block)?.[1] || 'message';
        const data = /data: (.*)/.exec(block)?.[1];
        if (data) handlers[event]?.(JSON.parse(data));
      }
    }
  });
  return () => ctrl.abort();
}
```
