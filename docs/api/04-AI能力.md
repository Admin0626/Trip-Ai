## 用户自定义模型规划 `/ai/planner`（已实现，均需登录）

| 方法 | 路径 | 行为 |
|---|---|---|
| GET | `/ai/planner/options` | 返回allowedHosts与allowLoopback，供页面显示可连接范围 |
| GET | `/ai/planner/usage` | 当前用户小时/日、全局日配额及当日模型操作统计，不接受他人用户ID |
| POST | `/ai/planner/test` | 真实短对话测试连接，不保存Key |
| POST | `/ai/planner/circuit` | 当前用户及连接的故障状态，不外呼/扣次/生成模型日志 |
| POST | `/ai/planner/generate` | 返回经过结构校验的行程预览，不直接保存 |
| POST | `/ai/planner/generate-stream` | 阶段/心跳/完整预览SSE；上游仍非流式 |
| GET | `/ai/planner/requests/{requestId}` | 本人任务状态，最近完成任务保留10分钟 |
| POST | `/ai/planner/requests/{requestId}/cancel` | 本人取消；提交/成功终态409，已取消幂等200 |

配额已实现：默认20次/用户小时、200次/用户日、2000次/全站日，北京时间固定窗口；测试连接及每一次生成尝试各计1次，结构重试额外扣次。配额拒绝为HTTP200/code429，Redis或配置不可用为HTTP200/code503。规则意图/匹配不扣模型额度。usage的quota包含hourly/daily/globalDaily，每项包含limit/used/remaining/resetAt；today包含operations/succeeded/failed/averageCostMs。实际响应及统计口径见[配额实测](../dev/AI配额与统计接口实测.md)、[开发复盘](../dev/AI配额与统计开发复盘.md)。

管理员`GET /admin/ai/recommend/log`已实现：ADMIN权限，current默认1（1—1000000）、size默认20（1—100）、可选正整数userId，返回PageResult，按id倒序；字段仅id/userId/scene/model/costMs/success/isFallback/createTime，不返回输入或上游正文。普通用户HTTP403，非法分页HTTP200/code400。其他后台AI配置接口仍按后文设计契约，不能据此视为已实现。

连接测试请求：

```json
{"connection":{"baseUrl":"http://localhost:11434/v1","model":"用户自己的模型ID","apiKey":""}}
```

模型ID须为ASCII字母数字及`._:/-`组合、≤50字符；Key可空（无鉴权本机服务），≤512个可打印ASCII字符。URL≤500字符，不含userinfo、query或fragment，后端追加`/chat/completions`；限制见[使用说明](../dev/用户自定义AI规划使用与开发文档.md)。测试成功data为`{"connected":true,"model":"..."}`，不保证该模型一定能生成符合结构的旅行规划。

生成请求增加query（JSON字符串5—1000字符，strip后≥5）、days（JSON整数1—14）、budget（JSON数字0.01—1000000）、peopleNum（JSON整数1—10）、可选startDate（yyyy-MM-dd，今天及以后，省略默认今天）。

```json
{
  "connection":{"baseUrl":"http://localhost:11434/v1","model":"qwen-example","apiKey":""},
  "query":"去大理旅行，喜欢自然风光，带父母，不要太赶",
  "days":3,"budget":3000,"peopleNum":2,"startDate":"2026-10-01"
}
```

`qwen-example`仅为结构示例，须替换成服务实际模型ID；日期也须按当前日期填写。成功data结构为`{draft:{title,dayList:[{dayIndex,title,summary,items:[...]}]},source:"USER_MODEL",model,attempts}`。item只保留已校验的title/timePoint/activity/transport/hotel/meal/tips/cost；attractionId固定0，sortNo按顺序生成。每天1—8项，天数必须一致；未知费用null。attempts为1或2，只有输出结构不合格才自动重试，认证失败/网络错误不自动重试。

code3004表示模型认证、限流、超时、响应过大、格式不合格或模板未初始化，返回安全提示，不返回供应商原始错误正文。code429表示配额、本人进行中的调用或单进程8个并发名额限制；熔断/半开占用/状态服务故障为code503。业务错误沿用HTTP200包装，匿名HTTP401。默认每次模型请求45秒，最多两次；响应≤1MiB，禁重定向。

模型熔断（已实现）：按认证用户、已验证规范化completion地址、模型和Key摘要隔离。每次外呼完成计样本，最近300秒至少10次且失败率严格大于30%开放600秒；冷却后下次实际调用仅一个半开探测，成功恢复并重置窗口，失败/90秒租约到期重新冷却。更换配置形成独立桶，仍受同一用户quota限制。熔断在配额前检查；未外呼的本地校验/并发/额度错误不计故障，额度拒绝释放已预留探测。半开结构失败后重试会被503阻止，不保证一定外呼两次。

`POST /ai/planner/circuit` 请求同test，data为 `{phase:"CLOSED"|"OPEN"|"HALF_OPEN",total,failed,failurePercent,minimumCalls,windowSeconds,cooldownSeconds,retryAt,retryAfterSeconds}`。retryAt为UTC ISO字符串或null；OPEN表示冷却截止，HALF_OPEN表示探测租约截止。OPEN剩余0表示允许竞争一次探测，状态查询不会自动外呼；total/failed是当前滑窗而非累计次数，窗口为空时OPEN仍可能有效。查询不创建空桶，但会处理样本/租约过期。真实故障与边界见[实测](../dev/模型熔断接口与页面实测.md)、[设计/配置与答辩复盘](../dev/模型熔断开发与答辩复盘.md)。

前端显式确认后另外调用已有`POST /plan`保存status=0草稿；生成接口没有数据库规划写入权限。支持新规划生成，原`/plan/{id}/ai-optimize`仍是未实现占位，不能混用。模型调用日志不含Key/地址/需求/完整响应，token默认0表示未采集，非零费用保证。详见[实际验收](../dev/用户自定义AI规划实测.md)。

### 用户规划阶段SSE（已实现）

`POST generate-stream`请求为`{requestId:"小写UUID",input:上面generate的完整输入}`，Authorization仍为Bearer，Accept为text/event-stream。成功HTTP200，Content-Type为`text/event-stream;charset=UTF-8`，Cache-Control为`no-cache, no-store`，X-Accel-Buffering为no。

每事件data为JSON `{requestId,data}`。start.data为`{state:"RUNNING"}`；progress为`{stage:"CONNECTING"|"GENERATING"|"VALIDATING"|"RETRYING",attempt:1|2}`；heartbeat为`{elapsedSeconds}`，默认每5秒。done.data与普通生成成功data完全一致。error.data为安全的`{code,message}`，包含3004模型错误、429额度、503依赖、401会话失效、408整体截止等。cancelled.data为`{code:499,message}`；499是事件业务码，已经开流的HTTP仍200。一任务仅一个done/error/cancelled，断连客户端可能收不到终态。

开流前参数、地址、并发和重复ID错误为HTTP200的普通JSON R；匿名仍HTTP401。默认容器超时125秒，在截止前一个心跳周期主动停止；前端130秒。配置见[开发复盘](../dev/AI规划SSE开发与答辩复盘.md)。客户端必须检查Content-Type与终态，EOF不代表成功。不自动补发模型请求，可手动使用普通generate。

状态data为`{requestId,state,startedAt,finishedAt}`，时间为UTC ISO字符串，尚未完成时finishedAt=null；state为RUNNING/CANCELLING/FINISHING/SUCCEEDED/FAILED/CANCELLED。取消成功data为`{requestId,accepted:true,state}`，进行中可能为CANCELLING。完成取消任务再次取消仍成功；FINISHING/SUCCEEDED/FAILED等不可取消状态code409。他人、未知/过期任务code404；请求ID保留期间不能复用。

新旧API共用本人1个、单实例8个并发名额。取消触发HTTP future取消，已准入额度不退，不将本地停止记为供应商故障，半开探测中性释放；实际供应商计费不保证终止。断连靠写入/心跳检测；退出、刷新令牌轮换或禁用会停止原流。任务与取消路由为实例内状态，需要单实例/同实例路由，无跨节点恢复。实测见[116项接口、32项生命周期、40项页面/解析记录](../dev/AI规划SSE接口与页面实测.md)。

**POST /ai/recommend/intent**

请求：
```json
{ "query": "我想 10 月去云南玩 5 天，预算 3000 左右，喜欢自然风光和美食，不要太赶" }
```

当前规则模式响应的 `data`（外层仍为统一的 code/message/data/timestamp）：
```json
{
  "intent": {
    "destinations": ["云南"],
    "days": 5,
    "budget": 3000,
    "budgetLevel": "medium",
    "preferenceTags": ["自然风光", "美食"],
    "companions": null,
    "pace": "relaxed",
    "travelMonth": 10,
    "mustVisit": [],
    "avoid": []
  },
  "confidence": 0.3,
  "source": "RULE_FALLBACK"
}
```
`source`：LLM / RULE_FALLBACK（降级标识）

当前实现始终为 `RULE_FALLBACK`。未提取到信息时confidence为0.1，否则0.3，均需用户确认；不是概率估计。query必须是JSON字符串，原始长度不超过500，去除首尾空白后不少于5（Java UTF-16字符计数）。不合格请求按现有业务协议返回HTTP 200、code=400；未登录为HTTP 401、code=401。超长输入明确拒绝，不静默截断；这是当前子阶段对BR-AIC-01“截断并提示”的实施差异，后续前端需展示校验提示。

规则只提取明确的阿拉伯数字天数、预算、月份和词表关键词；中文数字、相对日期、复杂否定和景点语义暂不支持，mustVisit保留空列表。区间与矛盾数字置null。目的地来自数据库在架词表，最多3个；正向标签最多5个。测试边界与证据见 [接口实测](../dev/第3批意图降级接口实测.md)。

**POST /ai/recommend/match**

请求：
```json
{ "intent": { "destinations": ["云南"], "days": 5, "budget": 3000, "preferenceTags": ["自然风光"], "avoid": ["购物"] }, "topN": 5 }
```

基础模式响应data的结构示例（具体路线以数据库为准，非模型结果）：
```json
{
  "totalCandidates": 1,
  "recallDetail": { "cf": 0, "content": 1, "hot": 0, "behavior": 0 },
  "costMs": 12,
  "source": "RULE_BASED",
  "unsupportedCriteria": [],
  "effectiveCriteria": {"destinations":["云南"],"days":5,"budgetMin":null,"budgetMax":3000,"preferenceTags":["自然风光"],"avoid":["购物"]},
  "savedPreferenceFields": [],
  "list": [
    {
      "routeId": 201,
      "title": "云南大理丽江香格里拉 5 日纯玩",
      "coverImg": "https://oss.../r201.jpg",
      "destinationName": "云南",
      "days": 5,
      "price": 2980.00,
      "tags": ["自然风光", "摄影"],
      "recallScore": 1.0,
      "llmScore": null,
      "reason": "目的地符合、天数一致、人均参考价在预算内、自然风光",
      "highlightMatch": ["目的地符合", "天数一致", "人均参考价在预算内", "自然风光"]
    }
  ]
}
```

基础匹配规则：

- intent必须是对象；空对象允许按用户评分浏览在架路线。topN省略或null时为5，仅接受1—20的JSON整数。
- destinations可省略/null/空数组，最多3项，去重后精确匹配目的地名称、省份或城市，多项取OR；未知目的地返回空集，不擅自放宽条件。每项1—100字符，去除首尾空白。
- days可空，整数1—365，完全匹配；budget可空，整数1—1000000，对比人均路线参考价上限，包含等于边界。数字字符串、浮点数、布尔值均不接受。
- 新区间budgetMin/budgetMax接受0—99999999.99的JSON数字，最多两位小数；0/null表示对应端不限，包含等于边界，允许上下限相等，拒绝下限大于上限。可仅指定一端；不能把旧budget与有效新区间同时设置。旧budget的整数规则保持不变。
- preferenceTags最多8项，avoid最多21项，共用21个标签：自然风光、历史文化、美食、亲子、摄影、探险、海滨、都市、购物、温泉、滑雪、徒步、自驾、民俗、宗教、康养、古城、慢生活、海边、夜游、露营。先去首尾空白再去重；本次明确的偏好与排除重叠返回code400。偏好只影响排序，排除标签是硬过滤。数据库标签按逗号完整项匹配，海滨/海边尚不做同义词扩展。
- 路线与所属目的地都必须上架且未逻辑删除。按偏好命中数降序、平均用户评分降序、路线ID升序返回topN；totalCandidates为截断前的筛选数量。
- recallScore是命中偏好数/去重偏好数，无偏好时为0；不是模型分数或概率。llmScore始终null，source为RULE_BASED；cf/hot/behavior计数为0，仅有content召回。
- 其余非空intent字段返回于unsupportedCriteria，例如companions、pace、travelMonth、mustVisit、budgetLevel，不参与筛选。页面固定说明尚未支持的条件，不宣称全部理解。
- 无结果返回HTTP200/code200及空list；无效参数HTTP200/code400；匿名HTTP401/code401。匹配过程不调用模型、不写模型调用日志。

保存偏好需显式选择：请求顶层增加`useSavedPreference:true`；省略/null/false保持旧行为，仅接受JSON布尔值，字符串`"true"`返回code400。偏好来自认证身份，传入userId不能切换用户。

```json
{"intent":{"destinations":["云南"]},"topN":5,"useSavedPreference":true}
```

只有intent缺少字段键时才补默认值：days取preferredDays；整个预算组（budget/budgetMin/budgetMax）都缺键时才取保存范围；preferenceTags/avoid分别取保存标签。明确传null/[]表示清空，不能再次补回。预算只指定一端时另一端不限。本次明确偏好优先于保存的冲突避雷，本次明确避雷优先于保存的冲突偏好；两项都明确且重叠仍拒绝。companions/pace不从保存偏好补入筛选。`effectiveCriteria`返回最终规范化条件，`savedPreferenceFields`返回实际补入的days/budgetRange/preferenceTags/avoid字段名。

前端入口 `/recommend`：默认勾选“参考已保存偏好”，读取本人设置后为规则解析的未知项预填，并标注来源；用户编辑/清空后显式确认。页面提交全部显示条件的快照，因此页面预填时savedPreferenceFields可以为空，effectiveCriteria与确认内容一致。关闭开关移除仍未被用户修改的默认值，保留手动编辑。修改需求废弃旧解析，修改条件清空旧结果，过期异步响应不会覆盖当前条件。参见[本批实测](../dev/用户侧收尾接口与页面实测.md)、[开发复盘](../dev/用户侧收尾开发与答辩复盘.md)。

## 本地知识管理与来源检索（已实现，非生成式聊天）

## 推荐/问答SSE接入约定（设计，未实现）

本节不是已经实现的用户规划阶段SSE契约。用户规划采用上方独立事件、5秒心跳和125秒容器配置，没有token、references或自动降级重发。

| 项 | 约定 |
|---|---|
| 请求方式 | `POST` + `fetch` 流式读取（原生 EventSource 不支持自定义头，故用 fetch + ReadableStream） |
| 响应头 | `Content-Type: text/event-stream`、`Cache-Control: no-cache`、`X-Accel-Buffering: no` |
| 事件类型 | `start` / `intent` / `recall` / `token` / `references` / `error` / `done` |
| 心跳 | 每 15s 发送 `: heartbeat` 注释行 |
| 超时 | 服务端 120s，前端 130s 未收到 `done` 则主动断开并提示重试 |
| 错误 | 发送 `event: error` + `data: {"code":3001,"message":"AI 服务暂时不可用，已为你切换到基础推荐"}` |
| 取消 | 前端 AbortController 中断，服务端检测连接断开后停止生成 |

前端调用示例：
```ts
export function ssePost(url: string, body: any, handlers: Record<string, (d: any) => void>) {
  const ctrl = new AbortController();
  fetch(url, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json', Authorization: `Bearer ${getToken()}` },
    body: JSON.stringify(body),
    signal: ctrl.signal
  }).then(async res => {
    const reader = res.body!.getReader();
    const decoder = new TextDecoder();
    let buf = '';
    while (true) {
      const { done, value } = await reader.read();
      if (done) break;
      buf += decoder.decode(value, { stream: true });
      const blocks = buf.split('\n\n');
      buf = blocks.pop() || '';
      for (const block of blocks) {
        const event = /event: (\w+)/.exec(block)?.[1] || 'message';
        const data = /data: (.*)/.exec(block)?.[1];
        if (data) handlers[event]?.(JSON.parse(data));
      }
    }
  });
  return () => ctrl.abort();
}
```
