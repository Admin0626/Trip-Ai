## 认证模块 `/auth`

| 方法 | 路径 | 说明 | 权限 |
|---|---|---|---|
| POST | `/auth/register` | 用户注册 | 公开 |
| POST | `/auth/login` | 账号密码登录 | 公开 |
| POST | `/auth/logout` | 退出登录（Token 加入黑名单） | 登录 |
| POST | `/auth/refresh` | 刷新 Token | 公开 |
| POST | `/auth/send-code` | 发送邮箱验证码 | 公开 |
| POST | `/auth/reset-password` | 重置密码 | 公开 |

当前已实现：注册、登录、`/auth/me`、服务端退出和 refresh 轮换。邮箱验证码/找回密码仍为设计契约，尚未接入邮件服务。

## 用户设置 `/user`

| 方法 | 路径 | 说明 | 权限 |
|---|---|---|---|
| GET/PUT | `/user/profile` | 读取/修改昵称、头像、手机号、邮箱、城市 | 登录 |
| PUT | `/user/password` | 校验旧密码后修改，新密码会使已有会话失效 | 登录 |
| GET/PUT | `/user/preference` | 旅行偏好、避雷标签、预算、天数、同行人、节奏 | 登录 |
| GET | `/user/stats` | 收藏、预约、评论、规划、对话计数 | 登录 |

头像由 `POST /file/upload` 上传真实 PNG/JPEG 后使用返回的本站路径。反馈闭环见 `POST /feedback`、`GET /feedback/my/page`。完整实测见[基础功能接口实测](../dev/基础功能接口实测.md)。

**POST /auth/register**

请求：
```json
{
  "username": "traveler01",
  "password": "abc123456",
  "nickname": "小旅",
  "phone": "13800000000",
  "email": "test@example.com",
  "emailCode": "864213"
}
```

响应 `data`：
```json
{ "userId": 1001, "username": "traveler01" }
```

**POST /auth/login**

请求：
```json
{ "username": "traveler01", "password": "abc123456" }
```

响应 `data`：
```json
{
  "accessToken": "eyJhbGciOiJIUzI1NiJ9...",
  "refreshToken": "eyJhbGciOiJIUzI1NiJ9...",
  "expiresIn": 7200,
  "userInfo": {
    "id": 1001,
    "username": "traveler01",
    "nickname": "小旅",
    "avatar": "https://oss.../a.png",
    "role": "USER",
    "city": "杭州"
  }
}
```
