## 认证模块 `/auth`

| 方法 | 路径 | 说明 | 权限 |
|---|---|---|---|
| POST | `/auth/register` | 用户注册 | 公开 |
| POST | `/auth/login` | 账号密码登录 | 公开 |
| POST | `/auth/logout` | 退出登录（删除当前Redis白名单会话） | 登录 |
| POST | `/auth/refresh` | 刷新 Token | 公开 |
| POST | `/auth/send-code` | 发送邮箱验证码 | 公开 |
| POST | `/auth/reset-password` | 重置密码 | 公开 |

当前已实现：注册、登录、`/auth/me`、服务端退出和 refresh 轮换。邮箱验证码/找回密码仍为设计契约，尚未接入邮件服务。

## 用户设置 `/user`

| 方法 | 路径 | 说明 | 权限 |
|---|---|---|---|
| GET/PUT | `/user/profile` | 读取/修改昵称、头像、手机号、邮箱、城市 | 登录 |
| PUT | `/user/password` | 校验旧密码后修改，新密码会使已有会话失效 | 登录 |
| GET/PUT | `/user/preference` | 旅行偏好、避雷标签、预算、天数、同行人、节奏 | 登录 |
| GET | `/user/stats` | 收藏、预约、评论、规划、对话计数 | 登录 |

头像由 `POST /file/upload` 上传真实 PNG/JPEG 后使用返回的本站路径。反馈闭环见 `POST /feedback`、`GET /feedback/my/page`。完整实测见[基础功能接口实测](../dev/基础功能接口实测.md)。

2026-09-28用户侧收尾：`/user/profile`显示收藏、预约、评论、规划4项个人统计并提供刷新/重试。stats始终统计当前身份；收藏按当前收藏记录，预约含所有状态（取消/完成也计入），评论及规划排除逻辑删除，对话按未删除会话数返回chatCount，但尚未完成的对话产品不在页面展示。

偏好preferenceTags最多8项、avoidTags最多5项，使用[AI匹配章节](04-AI能力.md)列出的21个标签；两组不得重叠。budgetMin/budgetMax为0—99999999.99且最多两位小数，保存时要求下限小于上限，或均为0表示不限；常用天数为1—30整数/null。保存的同行人和节奏暂不参与规则匹配。参见[本批实测](../dev/用户侧收尾接口与页面实测.md)。

前端刷新使用同源Web Locks协调多标签页，重新读最新令牌后最多重放一次；登录态以trip_authSession整组写入，旧3个键保留兼容镜像。新登录产生epoch，刷新保持epoch；退出/换账号/重新登录后的旧响应不能覆写新会话或重放旧请求。页面按epoch重新挂载清除旧用户表单，退出受保护页跳登录、失去管理员身份离开后台；正常刷新不重挂载。无Web Locks时明确提示重新登录，不尝试并发旋转；网络故障保留登录态供重试。生产需HTTPS，同源地址/端口才能共享锁和localStorage。后端刷新CAS机制保持不变。

### 已登录用户修改密码

`PUT /user/password`仅接受`oldPassword`、`newPassword`两个字符串字段，不能传入目标用户ID。新密码8—20位且含字母和数字，不能与旧密码相同；身份来自access token。成功返回`{"code":200,"message":"success","data":null}`（另含timestamp），前端应清除本地登录态并重新登录。

成功会使该用户所有已有access/refresh会话失效；不是仅清除当前浏览器。错误旧密码和格式错误返回HTTP200/code400；旧密码重新登录返回HTTP200/code1001；并发更新冲突返回业务409。后续旧access被JWT过滤器拒绝为HTTP401/code401，旧refresh在控制器被拒绝为HTTP200/code401。实测、限制和答辩说明见[改密实测](../dev/改密与会话失效接口实测.md)、[开发复盘](../dev/改密与会话失效开发复盘.md)。

**POST /auth/register**

请求：
```json
{
  "username": "traveler01",
  "password": "abc123456",
  "nickname": "小旅",
  "phone": "13800000000",
  "email": "test@example.com",
  "emailCode": "864213"
}
```

响应 `data`：
```json
{ "userId": 1001, "username": "traveler01" }
```
