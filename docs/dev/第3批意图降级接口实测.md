# 第3批意图降级接口实测

测试日期：2026-09-27。用户明确要求暂不接真实模型，本次测试的是实际运行的Spring Boot接口和MySQL日志，未调用或模拟真实模型，不评价模型语义准确率。

## 环境与复现

- 后端：Spring Boot 4.0.8，Maven使用JDK21、Java17编译目标。
- 本地地址：`http://localhost:8080/api`；已有MySQL `trip_llm` 与Redis服务，不重建或清空演示库。
- `application.properties` 默认 `spring.ai.model.chat=none`，无需模型密钥。
- 脚本使用本地mysql客户端；数据库密码读取MYSQL_PASSWORD，未设置时沿用开发默认配置。用户名root与开发数据库一致。

从仓库根目录分别在两个终端运行：

```powershell
cd trip-server
mvn spring-boot:run
```

```powershell
cd trip-server
mvn test
python scripts/batch3_intent_acceptance.py
```

验收脚本创建唯一专用账号，真实注册、登录并携带JWT请求；每次运行保存新时间戳JSON，逐项落盘，不覆盖旧证据。finally按专用用户ID删除其日志、偏好和账号，不修改已有业务数据。鉴权请求和响应中的凭据不保存。

## 发现的问题、原因与解决方案

| 编号 | 现象与证据 | 原因 | 解决方案与回归 |
|---|---|---|---|
| B3-01 | `{"query":12345}`错误返回code200，并写入一条日志；因此无效请求日志数与总日志数断言也失败 | Jackson把数字自动转换为String，字符长度验证无法识别原始JSON类型 | 请求DTO保留原始Object类型，控制器先检查instanceof String，再检查长度；回归返回code400且不写日志 |
| B3-02 | “3月到5月”得到3，“预算3000元到5000元”得到3000，“3天至5天”得到3 | 正则命中了带单位区间的左端，误认为确定值；新增单测失败为`expected: <null> but was: <3>` | 识别带/不带单位的区间并将对应字段置null，预算等级同步null；3项HTTP回归及单测通过 |
| TEST-01 | 首次脚本注册code400，随后读取用户ID为空导致ValueError | b3前缀加纳秒时间戳超过注册用户名20字符上限 | 改为19字符UUID夹具名，并在注册失败后明确终止；后续两轮成功创建及清理账号 |
| ENV-01 | Maven启动失败，AccessDeniedException指向用户目录下的resolver-status.properties | 沙箱禁止写工作区外的Maven依赖缓存 | 授权后重跑本地服务启动，成功监听8080；与业务接口或模型密钥无关 |

## 验收范围

没有真实模型调用，也没有测试模型超时、重试、输出Schema或提示词渲染。未添加前端页面，未重跑第2批浏览器与111项验收，历史证据保持原状。没有开展并发负载、配额和生产安全验收。

当前规则解析是保守兜底：否定子句整体过滤可能漏掉同一子句中的正向信息；目的地是子串词表匹配，不支持消歧；中文数字、相对日期和复杂范围语义不保证提取，必须人工确认。无模型调用时llm_call_log.success=0表示模型未成功调用，不表示本次HTTP接口失败；模型成功率统计将来须排除rule-only样本。
