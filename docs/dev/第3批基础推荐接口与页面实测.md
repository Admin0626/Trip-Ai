## 实际接口响应

真实请求的intent为专用测试省份`match_dcd76fe23c`、days=5、budget=2000、preferenceTags=[自然风光,美食]，topN=5。

实际HTTP200/code200结果：totalCandidates=2、source=RULE_BASED、content=2、cf/hot/behavior=0。路线236（价格1000、双标签）排在路线237（价格1500、仅美食）之前，recallScore分别1.0与0.5，llmScore均为null。双标签路线平均用户评分3，单标签路线评分5，验证了标签优先于评分。测试路线和目的地已删除，不作为永久演示数据。

将预算改成1000仍包含路线236；改成999返回空集。topN=1只返回1条但totalCandidates仍为2。输入目的地`' OR 1=1 --`或`%`返回空集，SQL字符作为参数值处理，没有拼入SQL语法。

16项非法参数检查均实际返回HTTP200/code400：缺失intent、days=0/366/字符串/小数/布尔值、负预算/超上限预算、目的地非数组/null元素/超过3项、未知标签、偏好与排除重叠、topN=0/21/字符串。匿名实际HTTP401/code401。

其他断言验证：路线下架/软删除、所属目的地下架/软删除都被排除；完整标签匹配不会混淆“美食街”；重复标签不增加分数；未支持的节奏和月份列入unsupportedCriteria；空条件合法；不写模型调用日志。测试创建8条路线、3个目的地和1个用户，finally按本次ID清理。

## 边界

本阶段不是LLM推荐，也不是协同过滤、多路召回、向量搜索或模型重排。未实现配额、熔断、SSE和RAG。数据库逗号标签按规范完整项匹配，不处理历史脏数据中的额外空格。没有进行大规模负载测试。预算是路线人均参考价，非整趟旅行总费用；月份、节奏、同行人和必去景点不用于匹配。前端主包约1.12MB的既有构建警告尚未优化。
