## 二、配置文件写什么

### `application.yml`（公共，提交 git）

```yaml
spring:
  application:
    name: trip-server
  profiles:
    active: dev

server:
  port: 8080
  servlet:
    context-path: /api          # ★ 必配，见下方说明
  tomcat:
    max-swallow-size: -1        # ★ SSE 必需，先写上，第 3 批就靠它
```

**`context-path: /api` 为什么是必须的**：`02-接口文档` 的 Base URL 是 `http://localhost:8080/api`，所有接口路径都带 `/api`。约定是 Controller 里只写 `@RequestMapping("/auth")`，由 context-path 补齐。不配的话文档里每个 URL 都对不上。

**连带两个后果，别踩**：

1. Knife4j 地址是 **`http://localhost:8080/api/doc.html`**（`10-部署手册` §3.4 已同步为 `/api/doc.html`）
2. Spring Security 的 `requestMatchers("/auth/**")` **不要写 `/api/auth/**`** —— context-path 在 Servlet 容器层就剥掉了，Security 看到的是剥掉之后的路径

## 三、common 包写什么

### `R<T>` — 统一响应体

字段严格照 `02` §1.2：`code` / `message` / `data` / `timestamp`（毫秒）。

需要这几个静态方法：
- `R.ok()`、`R.ok(T data)`
- `R.fail(ResultCode rc)`、`R.fail(int code, String message)`

### `PageResult<T>` — 分页响应体

字段照 `02` §1.3：`records` / `total` / `current` / `size` / `pages`。

**关键点**：给一个 `PageResult.of(IPage<T> page)` 静态方法，把 MyBatis-Plus 的 `Page` 转成这个结构。**不要让 Controller 直接返回 MP 的 `Page`** —— 它的 JSON 字段名（`records`/`total`/`size`/`current`/`pages`/`orders`/`optimizeCountSql`…）和接口文档对不上，前端会拿到一堆无用字段。

### `ResultCode` — 状态码

照 `02` §1.5 一张表抄全，别只写 200 和 500。至少要有：

```
200 成功 / 400 参数校验失败 / 401 未登录 / 403 无权限 / 404 不存在 / 409 业务冲突 / 429 限流 / 500 服务器错误
1001 用户名或密码错误 / 1002 账号已被禁用
2001 路线不存在或已下架 / 2002 预约人数已满 / 2003 预约截止日期已过
3001 AI 服务暂时不可用 / 3002 意图解析失败 / 3003 知识库无相关内容
```

### `BizException`

`extends RuntimeException`（**不要做成受检异常**），字段带 `ResultCode` 或 `code + message`。业务里 `throw new BizException(ResultCode.USER_NOT_FOUND)` 这种写法。

### `GlobalExceptionHandler`

`@RestControllerAdvice`，至少覆盖 5 类：

| 异常 | 返回 |
|---|---|
| `BizException` | 它自带的 code |
| `MethodArgumentNotValidException` | 400 + 第一个字段的错误消息 |
| `ConstraintViolationException` | 400 + 消息 |
| `AccessDeniedException` | 403 |
| `Exception` | 500，**日志里打全堆栈，响应里只给一句「服务器内部错误」** |

> ⚠️ **`@RestControllerAdvice` 管不到 JWT 过滤器里抛的异常。** 过滤器跑在 DispatcherServlet 之前，还没进 Spring MVC 的异常处理链。所以 `JwtAuthenticationFilter` 里遇到 token 非法/过期，**必须自己 catch 并直接往 `response` 里写 JSON**（`response.setStatus(401)` + `setContentType("application/json;charset=UTF-8")` + 手写 `R.fail(...)` 的 JSON）。指望 advice 兜底的结果是前端收到一个空的 500。

### `JwtUtil` — ⚠️ JJWT 0.12 的 API 和 0.11 完全不同

```java
// 密钥：必须 ≥ 32 字节，否则 HS256 直接抛 WeakKeyException
SecretKey key = Keys.hmacShaKeyFor(secret.getBytes(StandardCharsets.UTF_8));

// 生成
String token = Jwts.builder()
        .subject(String.valueOf(userId))
        .claim("role", role)
        .issuedAt(new Date())
        .expiration(new Date(System.currentTimeMillis() + expireSeconds * 1000))
        .signWith(key)
        .compact();

// 解析：0.12 是 parseSignedClaims().getPayload()
//       0.11 的 parseClaimsJws().getBody() 已经删了，抄旧文章一定编译不过
Claims claims = Jwts.parser().verifyWith(key).build()
        .parseSignedClaims(token).getPayload();
```

## 四、认证与安全

### `LoginUser implements UserDetails`

装 `userId` / `username` / `role`。

- `getAuthorities()` 返回 `List.of(new SimpleGrantedAuthority("ROLE_" + role))`
- ⚠️ **必须带 `ROLE_` 前缀**。`hasRole("ADMIN")` 会自动补前缀去比，authority 写成 `ADMIN` 的话 `hasRole` 永远不通过（这是个查半天查不出来的坑）

### `UserDetailsServiceImpl implements UserDetailsService`

按用户名查 `sys_user`：
- 查不到 → `UsernameNotFoundException`
- `status = 0`（禁用）→ 抛业务异常对应 `1002`
- 密码交给 `PasswordEncoder` 比，不要自己 `equals`

### `PasswordEncoder` — ⚠️ 只能用 BCryptPasswordEncoder

```java
@Bean
public PasswordEncoder passwordEncoder() {
    return new BCryptPasswordEncoder();       // 就这一个，别换
}
```

**绝对不要用 `PasswordEncoderFactories.createDelegatingPasswordEncoder()`。** `data.sql` 里存的哈希是**裸的** `$2a$10$2QTv8eyBBSE3x66r...`，没有 `{bcrypt}` 前缀。委派编码器靠前缀选算法，拿到没有前缀的哈希会抛：

```
IllegalArgumentException: There is no PasswordEncoder mapped for the id "null"
```

### `JwtAuthenticationFilter extends OncePerRequestFilter`

1. 读 `Authorization` 头，取 `Bearer ` 之后的部分；没有就 `chain.doFilter` 直接放行（让 Security 的授权规则决定是 401 还是放行）
2. 有 token → 解析 → 构造 `UsernamePasswordAuthenticationToken` 塞进 `SecurityContextHolder`
3. **不做数据库查询**（JWT 自包含）；需要用户的实时状态（是否被封禁）就查 Redis，不要每次请求打库
4. 解析失败 → 按上面说的，**自己写 401 响应**，不要往外抛

### `SecurityConfig` — Spring Security 7 写法

```java
@Configuration
@EnableWebSecurity
@EnableMethodSecurity          // 用 @PreAuthorize 必须加，否则注解静默失效
public class SecurityConfig {

    @Bean
    public SecurityFilterChain filterChain(HttpSecurity http,
                                           JwtAuthenticationFilter jwtFilter) throws Exception {
        http
            .csrf(AbstractHttpConfigurer::disable)
            .cors(Customizer.withDefaults())
            .sessionManagement(s -> s.sessionCreationPolicy(SessionCreationPolicy.STATELESS))
            .authorizeHttpRequests(auth -> auth
                // ★ Security 7 必须显式放行 ERROR/FORWARD 派发，否则异常响应会被拦成 401
                .dispatcherTypeMatchers(DispatcherType.ERROR, DispatcherType.FORWARD).permitAll()
                // 路径里不带 context-path
                .requestMatchers("/auth/**", "/doc.html", "/webjars/**",
                                 "/v3/api-docs/**", "/swagger-ui/**",
                                 "/actuator/**", "/files/**").permitAll()
                .requestMatchers(HttpMethod.GET, "/destination/**", "/route/**").permitAll()
                .requestMatchers("/admin/**").hasRole("ADMIN")
                .anyRequest().authenticated())
            .addFilterBefore(jwtFilter, UsernamePasswordAuthenticationFilter.class);
        return http.build();
    }
}
```

要点：
- **`permitAll` 写在前、具体的写在笼统的前面**，规则是「首个匹配生效」
- 结尾用 `.anyRequest().authenticated()`（默认拒绝），不要图省事 `permitAll()`
- 静态资源和文档路径要放行，否则 `/doc.html` 打不开

### `MybatisPlusConfig`

```java
@Configuration
@MapperScan("com.trip.module.**.mapper")     // 或每个 Mapper 上写 @Mapper
public class MybatisPlusConfig {
    @Bean
    public MybatisPlusInterceptor mybatisPlusInterceptor() {
        MybatisPlusInterceptor i = new MybatisPlusInterceptor();
        i.addInnerInterceptor(new PaginationInnerInterceptor(DbType.MYSQL));
        return i;
    }
}
```

⚠️ `PaginationInnerInterceptor` 依赖第〇节那个 `mybatis-plus-jsqlparser`。

## 五、业务模块

- `SysUser` 字段逐个对照 `sql/schema.sql` 的 `sys_user`，`@TableName("sys_user")`
- `AuthController` 三个接口按 `api/01` 的请求/响应示例实现：`POST /auth/login`、`POST /auth/register`、`GET /auth/me`
- DTO 用 `@NotBlank` / `@Size` 等 `jakarta.validation` 注解（**是 `jakarta.` 不是 `javax.`**），Controller 方法参数上 `@Valid`
- 分页入参统一用 `current` / `size` / `sortField` / `sortOrder`（`02` §1.4），记得校验 `size ≤ 100`
- 目的地的 `GET /destination/**`、路线的 `GET /route/**` 游客可读 → 已经在 SecurityConfig 里放行；写接口走 `/admin/**` 或加 `@PreAuthorize("hasRole('ADMIN')")`
- 路线详情要带行程明细（`route_day` → `route_place`），一次查完再组装，不要在循环里单查

## 六、这一批最容易卡住的 8 件事

| # | 现象 | 原因 / 对策 |
|:--:|---|---|
| 1 | `/doc.html` 404 | context-path 是 `/api`，实际地址是 **`/api/doc.html`**；另外 Security 必须放行 `/doc.html`、`/webjars/**`、`/v3/api-docs/**` |
| 2 | 登录报 `no PasswordEncoder mapped for the id "null"` | 用了委派编码器，换回 `new BCryptPasswordEncoder()` |
| 3 | `hasRole("ADMIN")` 永远不通过 | authority 少了 `ROLE_` 前缀，要 `ROLE_ADMIN` |
| 4 | `PaginationInnerInterceptor` 找不到类 | 漏了 `mybatis-plus-jsqlparser` 依赖 |
| 5 | token 过期时前端收到 500 而不是 401 | JWT 过滤器抛的异常 `@RestControllerAdvice` 接不到，必须在过滤器里直接写响应 |
| 6 | 抛异常时返回 401 而不是业务错误码 | Security 7 默认也鉴权 ERROR 派发，加 `.dispatcherTypeMatchers(DispatcherType.ERROR, DispatcherType.FORWARD).permitAll()` |
| 7 | 时间字段输出格式不对 / 变成 `[2026,9,19,16,32]` 这样的数组 | Jackson 3 默认已是 ISO 字符串；`spring.jackson.date-format` **对 LocalDateTime 无效**。用实体字段上的 `@JsonFormat(pattern="yyyy-MM-dd HH:mm:ss", timezone="GMT+8")` |
| 8 | 时间差 8 小时 | JDBC URL 的 `serverTimezone=Asia/Shanghai` + `spring.jackson.time-zone: Asia/Shanghai` 两个都要有 |

### 另外三条 Boot 3 → Boot 4 的断代差异（照抄旧教程会编译不过）

| 项 | Boot 3 / Security 6 | Boot 4 / Security 7 |
|---|---|---|
| 配置链式 | `http.csrf().disable().authorizeRequests()...and()` | `.and()` **已删除**，每个配置器单独 lambda |
| 授权方法 | `authorizeRequests()` / `antMatchers()` | `authorizeHttpRequests()` / `requestMatchers()` |
| 路径匹配器 | `AntPathRequestMatcher` / `MvcRequestMatcher` | **都已删除**，统一 `PathPatternRequestMatcher`；⚠️ **`**` 只能出现在模式末尾**，`/api/**/admin` 这种会在启动时直接抛异常 |
| Jackson 注解 | `com.fasterxml.jackson.annotation.*` | **不变**，还是这个包（Jackson 3 保留了注解包名） |
| Jackson 核心类 | `com.fasterxml.jackson.databind.ObjectMapper` | **`tools.jackson.databind.ObjectMapper`**（包名变了，IDE 自动 import 时注意看） |
| Jackson 异常 | 受检 `JsonProcessingException` | **`RuntimeException`**，不用再 try-catch |
