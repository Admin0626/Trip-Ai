## 关键响应与安全边界

资料查询和修改均返回统一 `code:200`，修改只接受昵称、头像、手机号、邮箱、城市；密码修改要求旧密码、新密码，新密码必须8—20位且同时含字母和数字。刷新接口返回新 access/refresh token，旧 refresh 返回 HTTP200/业务401；退出后原 access token 返回 HTTP401。Redis会话不可用时登录/认证返回业务503，不把会话当作“默认放行”。改密和多设备会话的实际验证见后续[改密与会话失效接口实测](改密与会话失效接口实测.md)。

偏好接口使用 `preferenceTags`、`avoidTags`、预算上下限、常用天数、同行类型和节奏；标签分别限制8/5个，重复标签、交叉标签、预算字符串和非法枚举会返回400。统计返回收藏、预约、评论、规划和对话数量，始终按JWT用户ID查询，不能传入他人ID。

目的地卡片现在跳转 `/destination/{id}`，详情显示简介、标签、季节、预算、在架景点和相关在架路线。公开接口强制只读上架且未删除内容：客户端传 `status=0` 不会绕过过滤；下架目的地的详情、景点和关联路线不可公开读取。

图片上传要求真实PNG/JPEG内容、≤5MB、尺寸≤6000×6000且像素≤2000万；返回随机本站 `/api/files/{uuid}.png|jpg`，文件名不接收用户路径。头像和反馈图片只接受本站上传路径或无用户信息的HTTP(S)地址，文件读取限制为随机名，防止路径穿越。

反馈接口支持提交、我的反馈分页；管理员能分页读取并回复状态0—3。普通用户访问管理员反馈返回HTTP403。首页轮播公开接口最多返回8张且过滤时间范围和下架目标，管理员轮播写接口限制URL、启用数量和跳转目标。

## 本轮发现与修复

| 问题 | 原因 | 修复 |
|---|---|---|
| 旧文档称基础功能全部完成 | 第1批只验收了用户端只读浏览，管理员与个人设置不在当轮范围 | 总览改为按模块列出已完成和未完成；本轮补齐日常闭环 |
| 目的地卡片点击后仍回列表 | 没有目的地详情页面和路由 | 新增详情页、景点/相关路线读取和移动布局 |
| 公开参数 `status=0` 可查询下架内容 | 读取服务直接信任客户端 status 参数，详情也只查ID | 公开控制器固定 status=1，详情/景点/路线校验父目的地上架 |
| 资料/偏好/退出只存在前端状态 | 后端没有设置接口和会话撤销 | 新增数据库读写、Redis会话白名单、刷新轮换、退出删除会话键 |
| 图片只按扩展名信任 | 文件上传入口缺失，头像地址可任意绑定 | ImageIO解析真实格式、尺寸/大小限制、随机文件名与路径校验 |
| 反馈表有设计但无应用闭环 | 没有用户/管理员控制器与页面 | 新增提交/查询/回复、反馈页面和管理员概览 |
