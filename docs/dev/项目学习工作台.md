# Trip-AI 项目学习工作台

2026-10-03。入口 `/workbench`，主导航增加“学习工作台”。这是面向项目介绍、学习和答辩的公开前端页面，无需登录。以当前实现为主，配合系统设计解释目标与交付边界。

## 工作台内容

| 视角 | 呈现方式 | 解释内容 |
|---|---|---|
| 系统总览 | 可点击连接图、节点说明、模块清单 | Vue → HTTP → Security → Controller → Service → Mapper/JDBC → MySQL，以及 Redis、用户模型规划和本地检索分支 |
| Spring 装配 | 依赖图、五步代码导览、条件模拟 | IoC/DI、Bean 注册、组件扫描、自动配置、Mapper 代理、构造器注入和候选冲突 |
| 请求链路 | 四个业务的分步回放 | 浏览路线、保存规划、AI SSE 规划、本地资料检索 |
| 前端协作 | 页面协作图、四态预览 | Router、Vue 单文件组件、ref、Pinia、API 模块、Axios、TypeScript 与运行时校验 |
| 接口实验 | 可修改身份/参数的请求响应面板 | Path/Query/Body、DTO/Entity/VO、R<T>、401/403/参数错误、分页上限 |
| 数据关系 | 主要实体关系图、提交/回滚模拟 | 私人规划三层数据、目录路线、知识分片、事务、MySQL/Redis 分工 |

所有连接图可用键盘选择节点。窄屏将节点纵向排布，并显示真实关系清单，避免纵向节点顺序被误读为调用顺序。学习视角保存在 URL 的 `view` 查询参数，可复制具体视角地址；刷新时保留视角。导出导览生成 Markdown，打印按钮打印当前视角。

## 实验边界

接口实验、Bean 装配和事务演示都是浏览器本地模拟，不发送业务 HTTP 请求，不访问数据库，不调用模型，不改变已有账号或行程。Token、数据 ID 和路线均为教学样例。接口实验只演示主要规则；例如它自身要求路线 size 为正整数，真实 `RouteController` 目前仅显式限制 size 上限为 100。

明确区分已实现与设计目标：阶段 SSE 已实现，模型逐 token 输出待开发；本地文本检索已实现，语义向量与生成式 RAG 待开发；Jev 未接入当前代码；运营大屏、模型重排、情感分析和生产云存储待实现；邮箱流程已实现，真实 SMTP 未配置。数据库表存在也不代表功能已交付。

## 验证结果

- `npm run build`：vue-tsc 与 Vite 生产构建通过。既有全站主包超过 500kB 提示仍存在；工作台按路由懒加载。
- `node scripts/workbench_browser.cjs`：真实 Edge 浏览器 **74/74**。检查公开入口、节点说明与代码、导览下载、缺失/冲突 Bean、构造器说明、四个请求回放、前端四态、分页上限/空结果、401/403/DTO 错误、模拟成功、事务提交/回滚、答题反馈、视角刷新保留，以及现有路线页的共享导航五档宽度与手机进入工作台。
- 六视角分别在 1440 / 1024 / 768 / 390 / 320px 检查，无页面横向溢出；检查手机关系清单。浏览器未处理异常 0，工作台业务 API 请求 0。
- 初次测试 4/5：测试定位器将导航标题与描述拼成无空格正则，无法匹配可访问名称。改为在 nav 内匹配实际标题后 66/66。补共享导航时两次 65/67：一次未等待懒加载页挂载，另一次在手机宽度查询隐藏的导航链接；脚本等待导航挂载、先在桌面查询，再打开手机菜单验证后最终 74/74。以上是验收脚本定位/等待问题，未发现相应页面故障。
- 没有创建测试账号、模型请求、MySQL/Redis 数据或需要清理的业务夹具；不重跑无关后端验收。实际后端服务可用性、付费模型质量和生产部署不是本次验收范围。

## 本地打开与分享

已有 Vite 5173 服务可直接访问 `http://127.0.0.1:5173/workbench`。未启动时，从 `trip-web` 运行 `npm run dev -- --host 127.0.0.1`。无需为工作台启动 MySQL、Redis 或后端，依赖已安装时即可预览。

举例：`/workbench?view=spring` 直接打开 Spring 视角，`/workbench?view=api` 直接打开接口实验。localhost 地址只供本机访问；分享给其他人时使用同一前端实际部署地址。生产托管需为 `/workbench` 和现有 SPA 路由配置 index.html 回退。本批只新增前端功能，无 SQL 迁移、后端接口变动或新增依赖。
