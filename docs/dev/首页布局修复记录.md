# 首页左右留白修复

日期：2026-10-03。分支codex/home-layout，基于main=ab1ad991871c782709bf40e48615cab103a95127（旅行助手PR #7已合并）。用户要求首页元素与其他页面一样留出左右空白。

原因：首页只使用container类，但现有container样式局限在导航/页脚组件的scoped样式内，首页没有宽度限制。1440px浏览器实测英雄区和内容区宽1440、左边界0；Element Plus栅格的负外边距还让scrollWidth变成1448。

修改：Home.vue根节点复用全局page-wrapper，最大宽1200px、居中、两侧内边距16px；英雄区限制在该容器，添加12px圆角及桌面32px/手机20px内边距。轮播、目的地、精选路线和热门路线均跟随同一容器，不新增全局container样式，不改变其他页面。

实际Edge核对（没有调用模型、修改用户或数据库）：

|视口|首页容器宽|英雄区/内容左边界|实际scrollWidth|
|---|---|---|---|
|1440px|1200px|136px|1440px|
|1024px|1024px|16px|1024px|
|390px|390px|16px|390px|

三种视口均没有横向溢出。原始几何证据：[layout.json](evidence/home-layout/layout.json)；[桌面](evidence/home-layout/home-1440.png)、[平板](evidence/home-layout/home-1024.png)、[手机](evidence/home-layout/home-390.png)。截图中部分既有外部图片尚未显示，本批没有修改图片请求或占位逻辑。
