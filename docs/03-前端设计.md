# 前端设计文档

> 项目：基于 LLM 的旅行行程推荐系统
> 技术栈：Vue 3.4 + Vite 5 + TypeScript + Pinia + Vue Router 4 + Element Plus + ECharts 5 + DataV

---

## 一、技术选型

| 领域 | 选型 | 说明 |
|---|---|---|
| 框架 | Vue 3.4（Composition API + `<script setup>`） | 类型友好、逻辑复用强 |
| 构建 | Vite 5 | 冷启动快、HMR 体验好 |
| 语言 | TypeScript 5 | 接口类型自动生成，减少联调成本 |
| UI 库 | Element Plus | 后台表格 / 表单成熟，用户端配合自定义组件 |
| 状态 | Pinia + persist 插件 | 用户信息、Token、AI 会话状态持久化 |
| 路由 | Vue Router 4 | 动态路由 + 权限守卫 |
| 请求 | Axios | 拦截器统一处理 Token 与错误码 |
| 图表 | ECharts 5 + vue-echarts | 大屏与统计图表 |
| 大屏装饰 | DataV（Vue3 版） | 边框、翻牌器、装饰条 |
| 富文本 | marked + highlight.js | AI 返回 Markdown 渲染 |
| 工具 | dayjs、lodash-es、VueUse | |
| 代码规范 | ESLint + Prettier + Husky + lint-staged | |

### 3.4 路由守卫逻辑

```ts
router.beforeEach((to) => {
  document.title = `${to.meta.title || ''} - 智游行程`;
  const userStore = useUserStore();
  if (to.meta.public) return true;
  if (!userStore.token) {
    return { path: '/login', query: { redirect: to.fullPath } };
  }
  if (to.meta.role && !to.meta.role.includes(userStore.role)) {
    return { path: '/403' };
  }
  return true;
});
```

```ts
  const preference = ref<Preference | null>(null);
  const role = computed(() => userInfo.value?.role ?? 'GUEST');
  const isAdmin = computed(() => role.value === 'ADMIN');

  async function login(payload: LoginDTO) { /* 存 token + userInfo */ }
  async function fetchProfile() { /* 拉取资料 + 偏好 */ }
  function logout() { /* 清空 + 跳登录 */ }

  return { token, refreshToken, userInfo, preference, role, isAdmin, login, fetchProfile, logout };
}, { persist: { pick: ['token', 'refreshToken'] } });
```

## 六、请求封装

### 6.1 `api/request.ts` 要点

| 能力 | 实现 |
|---|---|
| baseURL | `import.meta.env.VITE_API_BASE_URL` |
| 请求拦截 | 注入 `Authorization`，开启 loading（可配置静默） |
| 响应拦截 | `code === 200` 返回 `data`；401 触发刷新 Token 或登出；其他 code 弹 `ElMessage` |
| 错误处理 | 网络错误统一提示「网络异常，请稍后重试」 |
| 防重复 | 相同请求在 500ms 内自动取消前一个 |
| 类型 | 泛型 `request<T>()`，配合 `types/api.d.ts` 描述接口返回 |

### 6.2 TypeScript 类型策略

- 后端开启 SpringDoc，用 `openapi-typescript` 生成 `src/types/api.d.ts`
- 命令：`npm run gen:api`（读取 `http://localhost:8080/v3/api-docs`）
- 好处：接口字段改动前端立刻编译报错，答辩演示时不易翻车

### 7.3 交互反馈

- 所有列表空态使用统一 `EmptyState`（插画 + 文案 + 主行动按钮）
- 所有异步操作按钮进入 `loading` 态并禁用
- AI 长任务展示进度阶段（理解需求 → 检索候选 → 生成行程）
- 破坏性操作二次确认

### 7.4 AI 交互专项规范（重要）

| 场景 | 规范 |
|---|---|
| 输入等待 | 首 token 未到达前显示「AI 正在思考」三点动画，超过 8s 提示「正在努力生成，请稍候」 |
| 流式输出 | 逐字追加，Markdown 增量渲染，禁止每 token 全量重渲染（用 `requestAnimationFrame` 批量刷新） |
| 中断 | 提供「停止生成」，中断后已输出内容保留并标注「已停止」 |
| 失败 | 展示友好文案 + 「重试」按钮 + 自动降级提示（如已切换基础推荐） |
| 免责 | AI 生成内容标注「内容由 AI 生成，仅供参考」，符合合规要求 |
| 可编辑 | 意图解析结果允许用户修改后重新推荐，避免「一次解析定终身」 |

## 八、构建与部署

### 8.1 环境变量

```
# .env.development
VITE_API_BASE_URL=/api
VITE_PROXY_TARGET=http://localhost:8080

# .env.production
VITE_API_BASE_URL=https://travel.example.com/api
VITE_SCREEN_REFRESH=60000
```

### 8.2 Vite 代理

```ts
server: {
  port: 5173,
  proxy: {
    '/api': {
      target: 'http://localhost:8080',
      changeOrigin: true,
      // SSE 必须关闭缓冲
      configure: (proxy) => {
        proxy.on('proxyRes', (proxyRes) => {
          if (proxyRes.headers['content-type']?.includes('text/event-stream')) {
            proxyRes.headers['x-accel-buffering'] = 'no';
          }
        });
      }
    }
  }
}
```

### 8.3 打包与部署

| 项 | 方案 |
|---|---|
| 构建 | `npm run build` → `dist/` |
| 路由模式 | `createWebHistory`（Nginx 需配 `try_files $uri $uri/ /index.html`） |
| 用户端 / 管理端 / 大屏 | 同一工程，按路由区分入口，Nginx 同域部署 |
| 大屏投放 | 独立浏览器窗口 + F11 全屏，或 kiosk 模式 |
| 静态资源 | 开启 gzip / br 压缩，图片走 OSS |
