## 二、实施计划（6 个阶段）

| 阶段 | 内容 | 产出 |
|---|---|---|
| P1 基础框架 | 数据库建表、Spring Boot 脚手架、JWT 认证、统一响应、Knife4j | 可运行的骨架 + 登录接口 |
| P2 核心业务 | 用户、目的地、路线、行程明细、互动（点赞/收藏/预约/评论） | 完整 CRUD + 用户端浏览链路 |
| P3 前端骨架 | Vue3 工程、路由权限、布局、用户端页面、管理后台页面 | 前后端联调通过 |
| P4 LLM 接入 | Spring AI 集成、意图解析、混合推荐 + 重排、SSE 流式生成、RAG 问答 | AI 推荐与问答可用 |
| P5 数据分析与大屏 | 数据聚合接口、情感分析、AI 洞察、可视化大屏 | 大屏上线 |
| P6 打磨 | 性能优化、异常兜底、演示数据、文档、答辩材料 | 可交付系统 |

---

## 三、风险与应对

| 风险 | 应对 |
|---|---|
| LLM 响应慢影响体验 | 流式输出 + 前端骨架屏 + 首包超时降级 |
| LLM 调用成本高 | 结果缓存 + 配额限制 + 小模型处理简单任务 |
| 冷启动推荐效果差 | 热度召回兜底 + 运营人工加权 `recommend_weight` |
| 大屏数据量大查询慢 | Redis 缓存 + 定时预聚合宽表 |
| 迁移后原有逻辑遗漏 | 按功能模块逐条对照 Django 版清单，做验收用例 |
