# 接口文档（API Specification）

> 项目：基于 LLM 的旅行行程推荐系统
> Base URL：`http://localhost:8080/api`
> 协议：HTTP/1.1 ｜ 数据格式：JSON（文件上传为 multipart/form-data）
> 流式接口：`text/event-stream`（SSE）

---

## 一、通用约定

### 1.1 请求头

| 名称 | 必填 | 说明 |
|---|---|---|
| Content-Type | 是 | `application/json`（上传接口除外） |
| Authorization | 视接口 | `Bearer {accessToken}`，需登录的接口必填 |
| X-Request-Id | 否 | 链路追踪 ID，不传服务端自动生成 |

### 1.2 统一响应体

```json
{
  "code": 200,
  "message": "success",
  "data": {},
  "timestamp": 1758029290123
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| code | int | 业务状态码，200 表示成功 |
| message | string | 提示信息 |
| data | any | 业务数据，失败时为 null |
| timestamp | long | 服务端时间戳（毫秒） |

### 1.3 分页响应体

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "records": [],
    "total": 128,
    "current": 1,
    "size": 10,
    "pages": 13
  }
}
```

### 1.4 分页请求参数

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| current | int | 1 | 当前页 |
| size | int | 10 | 每页条数（最大 100） |
| sortField | string | — | 排序字段 |
| sortOrder | string | desc | asc / desc |

### 1.5 状态码表

| code | 说明 |
|---|---|
| 200 | 成功 |
| 400 | 参数校验失败 |
| 401 | 未登录 / Token 失效 |
| 403 | 无权限访问 |
| 404 | 资源不存在 |
| 409 | 业务冲突（如重复点赞、手机号已注册） |
| 429 | 请求过于频繁 / AI 配额已用尽 |
| 500 | 服务器内部错误 |
| 1001 | 用户名或密码错误 |
| 1002 | 账号已被禁用 |
| 2001 | 路线不存在或已下架 |
| 2002 | 预约人数已满 |
| 2003 | 预约截止日期已过 |
| 3001 | AI 服务暂时不可用（已降级） |
| 3002 | AI 意图解析失败 |
| 3003 | 知识库无相关内容 |

### 1.6 接口分组总览

| 前缀 | 模块 | 权限 |
|---|---|---|
| `/auth` | 认证 | 公开 |
| `/user` | 用户与个人中心 | USER |
| `/destination` | 目的地 | 公开读 / ADMIN 写 |
| `/route` | 路线 | 公开读 / ADMIN 写 |
| `/interaction` | 互动（点赞/收藏/预约/评论） | USER |
| `/plan` | 自主规划 | USER |
| `/ai/recommend` | AI 智能推荐 | USER |
| `/ai/chat` | AI 旅游问答 | GUEST+ / USER |
| `/analysis` | 数据统计与大屏 | ADMIN |
| `/admin/banner` | 轮播图 | ADMIN |
| `/admin/feedback` | 反馈 | USER 提交 / ADMIN 管理 |
| `/admin/config` | 推荐配置 | ADMIN |
| `/admin/prompt` | 提示词模板 | ADMIN |
| `/file` | 文件上传 | 登录用户 |

## 二、通用能力：文件上传 `/file`

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/file/upload` | 通用图片上传（jpg/png/webp，≤5MB） |
| POST | `/file/upload/batch` | 批量上传（≤9 张） |
| DELETE | `/file` | 删除文件 |

响应：
```json
{ "url": "https://oss.../2026/09/uuid.jpg", "name": "dali.jpg", "size": 238102 }
```

## 三、接口分组与分册索引

本文件只保留**通用约定**与**通用能力**。各业务模块的接口明细已按开发批次拆为 5 个分册：

| 分册 | 覆盖模块 | 接口前缀 | 功能编号 | 实现批次 |
|---|---|---|---|---|
| [api/01-认证与用户.md](api/01-认证与用户.md) | 登录注册、个人中心、偏好 | `/auth`、`/user` | USR-01 ~ USR-12 | 第 1 批 |
| [api/02-目的地与路线.md](api/02-目的地与路线.md) | 目的地、景点、路线、行程明细 | `/destination`、`/route` | DST / RTE | 第 1 批 |
| [api/03-互动与规划.md](api/03-互动与规划.md) | 点赞、收藏、预约、评论、自主规划 | `/interaction`、`/plan` | INT / PLN | 第 2 批 |
| [api/04-AI能力.md](api/04-AI能力.md) | AI 推荐、AI 问答、SSE 事件协议 | `/ai/*` | AIC / RAG | 第 3 批 |
| [api/05-数据与运营.md](api/05-数据与运营.md) | 统计大屏、轮播图、反馈、用户管理、推荐配置、提示词 | `/analysis`、`/admin/*` | INS / SYS | 第 4 批 |

**权限标记**：`公开` = 无需登录；`登录`/`USER` = 需登录用户；`ADMIN` = 仅管理员。

**SSE 接口清单**（事件协议详见 [api/04-AI能力.md](api/04-AI能力.md)）：

| 接口 | 用途 |
|---|---|
| `POST /ai/recommend/itinerary` | 流式生成细化行程 |
| `POST /ai/recommend/one-shot` | 一站式推荐 |
| `POST /ai/chat/ask` | RAG 问答流式回答 |
| `POST /plan/{id}/ai-optimize` | AI 优化规划 |
| `GET /analysis/realtime` | 大屏实时动态推送 |

**前端调用封装**：统一的 SSE 读取函数见 [`03-前端设计.md`](03-前端设计.md) 第六节。
