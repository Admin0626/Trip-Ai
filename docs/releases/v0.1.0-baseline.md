## 已完成的基础功能

| 模块 | 交付范围 |
|---|---|
| 用户及会话 | 注册/登录、资料及头像、偏好保存、改密、刷新和退出、多设备撤销、跨标签页刷新协调、个人记录统计 |
| 旅游内容 | 首页轮播、目的地及景点、路线筛选/详情、有效内容及上下架隔离 |
| 用户互动 | 点赞/收藏、预约创建/取消及名额保护、评论/回复、反馈提交及查看处理结果 |
| 自主规划 | 草稿/正式规划、每日项目编辑与排序/跨天移动、预算、复制/导出、从路线创建 |
| 基础推荐 | 无模型Key的规则意图解析、条件编辑确认、数据库路线匹配、保存偏好参与推荐及结果解释 |
| 基础后台 | 8模块导航、目录/路线/每日行程/轮播维护、预约处理、评论显隐、反馈处理、普通用户启停、脱敏AI日志 |
| 已实现的AI扩展 | 每用户地址/端口/模型/Key配置、兼容接口测试、非流式行程预览/结构校验/确认保存、共享配额/统计、隔离熔断及恢复 |

完整交付范围及历史阶段见[项目完成项总览](../dev/项目完成项总览.md)。Key只在页面内存使用，地址/模型仅按账号保存在当前浏览器；没有跨设备模型设置同步。

## 未完成及已知问题

- 邮箱验证码/验证、找回密码、账号注销尚未实现。
- 用户AI规划SSE进度/取消、RAG、真实模型意图、多路召回/模型重排、评论情感、已有规划就地AI优化尚未实现。
- 角色调整/用户导出等高级后台、提示词版本管理、批量导入和运营大屏尚未交付。
- 生产云存储、全局供应商熔断、跨节点模型并发上限、Redis集群/故障转移/负载验收尚未完成；前端主包约1.13MB警告保留。
- 这是本地开发/演示基线，数据库和JWT开发默认配置不能据此视为已满足生产部署要求。

详细操作与验收要求见[Git分支与合并流程](../dev/Git分支与合并流程.md)，后续进度接续[SESSION](../../SESSION.md)。
