## 五、编号体系速查

项目里所有东西都用编号互相引用，记住三套编号就够：

| 编号体系 | 格式 | 示例 | 定义在 | 用途 |
|---|---|---|---|---|
| **功能编号** | `模块码-两位序号` | `AIC-06` | `04` 第二章 | 需求、排期、提交记录、答辩索引 |
| **模块码** | 3 字母 | `USR` `DST` `RTE` `INT` `PLN` `AIC` `RAG` `INS` `SYS` | `04` 第二章 | 功能分组 |
| **业务规则编号** | `BR-模块-序号` | `BR-INT-05` | `08` 第三章 | 代码注释、单元测试命名 |
| **提示词编码** | 全大写下划线 | `INTENT_PARSE` | `09` / `seed_config.sql` | 代码里只允许出现 code，禁止硬编码正文 |
| **接口路径** | RESTful | `POST /ai/recommend/match` | `api/*` | 联调 |

**约定**：编号一经确定**只增不改**。需要新功能就往后追加 `AIC-14`，不要重排既有编号，否则历史文档、代码注释、提交记录全部失效。
